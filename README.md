# People List — Next.js

Projeto desenvolvido durante os estudos de **Desenvolvimento de Sistemas**, utilizando Next.js e TypeScript.

A aplicação trabalha com uma lista de pessoas e demonstra diferentes formas de organizar, tipar, filtrar e renderizar dados utilizando componentes e recursos do React/Next.js.

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- CSS
- ESLint
